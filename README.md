# Hebrew Sacrobosco Manuscripts Project

This research project harvests and analyzes catalogue records and digitized page images of Hebrew translations and commentaries on Johannes de Sacrobosco's *De sphaera* (including *Mar'eh ha-Ofanim*, *Sefer ha-Galgal*, and Moses Almosnino's commentary *Beit Elohim*).

Records come from the National Library of Israel (NLI / Ktiv) Alma catalogue through its public SRU endpoint. Page images come from NLI IIIF manifests.

The NLI **MMS ID** (18 digits) links everything: catalogue rows, manuscript folder names, `metadata.json`, page index and illustration IDs.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name sphaera --display-name "sphaera"
```

Step 4 also needs **CorDeep** (YOLOv5 trained on printed *Sphaera* editions by MPIWG), shared at
https://github.com/Euclides-EM/sphaera-cordeep. It has its own environment (Python 3.12 + torch), managed by
[uv](https://docs.astral.sh/uv/):

```bash
git clone https://github.com/Euclides-EM/sphaera-cordeep.git external/sphaera-cordeep
git -C external/sphaera-cordeep remote set-url --push origin DISABLED-read-only-copy
cd external/sphaera-cordeep && uv sync
```

The push URL is disabled so nothing can be sent back to the original repository. `external/` is git-ignored.

## Running the pipeline

Run from the project root, in order:

```bash
python code/01_scrape_metadata.py                      # catalogue harvest (re-runs all search terms)
python code/02_download_manuscripts.py --start 0 --limit 10   # page images; resumes, skips pages already on disk
python code/03_organize_metadata.py
python code/04_extract_illustrations.py                # CorDeep; --only <folder>, --conf, --overwrite
python code/04b_apply_extraction_review.py            # apply the manual review (see below)
python code/05_cluster_illustrations.py
python code/07_match_print_illustrations.py           # optional: print parallels (run before step 6)
python code/08_build_network.py                       # optional: network of prints + manuscripts (after step 7)
python code/06_build_visualizer.py
```

Then open `visualizer/index.html`. It links page images from `data/manuscripts/`, so keep `visualizer/` next to `data/`. The map tab needs internet access (Leaflet and OpenStreetMap tiles).

Step 2 reads the list of manuscripts from `data/metadata/raw/ALL_OPEN_MANUSCRIPTS.csv`. The script that produced that list (and `OPEN_MANUSCRIPTS_SURVEY.csv`, `TRULY_OPEN_MANUSCRIPTS.csv`) is not in the project.

Step 4 finds five CorDeep classes: Content Illustration, Decoration, Initial, Printer's Mark and Table; the class is
stored in `illustrations.csv`. Boxes covering more than 40% of a page (blank leaves, covers) are dropped. Microfilm
target cards ("START/END", resolution charts) and photographers' rulers still come through and must be removed by hand.
Manuscripts already extracted are skipped unless `--overwrite` is given.

Step 5 describes each crop with two pretrained image models (CLIP for what is depicted, DINOv2 for shape and
layout) and puts crops in a cluster only when every pair in it is similar enough (complete linkage). Crops with no
close match go to cluster 0. Only the diagrams in none of your named groups (`data/review/groups.json`) are clustered;
your groups are shown in the visualizer's **Groups** tab and also link manuscripts in the **Network** tab.

Step 7 embeds the print cluster images in `data/print_corpus/images/` with the same models as step 5 and pairs them with
manuscript diagrams using a hubness-corrected score (CSLS), in three tiers: strong, probable, possible. The
**Print Parallels** tab shows each matched print cluster next to its manuscript illustrations. Matches are
candidates to check by eye; a match does not say which way the borrowing went (some manuscripts predate print).

Step 8 organises the data for the **Network** tab. Every book (printed edition or manuscript codex) is a node.
`memberships.csv` records which book contains which visual unit: a print image cluster (`SAC_SIL_…`, from the
print corpus; for a manuscript, through a step-7 match with its tier) or a step-5 manuscript group. Two books are
linked by every unit they share (`edges.csv`, counts per match tier). The tab recomputes links from the memberships
for its filters (years, place, print-centre size, link types, match tier, minimum shared clusters), as a force
network or on a map. The CSVs can also be opened in Gephi.

**Persons** (step 3) are read from the MARC name fields of the manuscript records (100/700/600): name ($a, $c),
life dates ($d) and role ($e: author, translator, scribe, former owner, censor, ...). The catalogue records no
place of residence, so the Persons tab maps either where a person's manuscripts were written (only for roles tied
to the copy: scribes, owners, censors, annotators) or the places in `data/metadata/person_places.csv`.
The rows there are marked "please verify"; add a row per person (matched by the start of the name) and re-run steps 3 and 6.

## Reviewing extraction and clusters by hand

```bash
.venv/bin/python review_tool/server.py           # then open http://localhost:8766
```

**1 · Extraction**, one manuscript at a time. The screen opens on the first unchecked page, shown large with its
boxes; under it are the crops taken from that page, then all crops of the manuscript and a page overview.
Go through the pages with **Next page** (→) or press **N** to mark a page checked and move on; **U** jumps to the next
unchecked page. **＋ Add missing illustration** (B) draws a box around something the detector missed. Click a box to
select it, then drag it to move or drag a corner to resize (a corrected detector box is saved as your box and replaces
the original). Mark wrong detections with X or by clicking their crop, change the class with 1–5 or the menu, Z zooms.

Every diagram has **one place**: one of your named groups, or else (if it is in none) a computed cluster. Moving a
diagram into a group takes it out of any other group and out of its cluster.

**2 · Clusters (computed)**: step 5's clusters of the diagrams that are in none of your groups. They are never edited
by hand; select diagrams (or a whole cluster) and move them into a group (typing a new name starts a group).

**3 · My groups**: your named groups, in `data/review/groups.json`. Name and describe a group, take diagrams out (back
to their cluster), merge another group or a similar cluster into it, or delete it. "Not grouped" lists everything else.
⤢ on any diagram opens it large, with its group and the most similar diagrams anywhere.

**4 · Board (drag & merge)**: your groups (gold) and the clusters (white) as cards. Drag a card onto another to merge
(group onto group: merged; cluster onto group: the cluster joins it; cluster onto cluster: a new group), open a card
and drag single diagrams to another card, to "＋ New group" or to "Not grouped".

Every change is saved at once in `data/review/` (Undo restores the previous version; the last 200 versions are kept). **Apply & rebuild visualizer**
runs steps 4b, 5, 7, 8 and 6 (about a minute; only new crops are embedded) and the visualizer, also served at
http://localhost:8766/visualizer/, shows the reviewed data. The detector's own output (`illustrations.csv`) is never
changed, so step 4 can be re-run; your decisions refer to illustration ids.
